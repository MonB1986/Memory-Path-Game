About.

Memory Path Game is a memory game where you watch the dots light up and then tap them back in the same order. It starts off simple, but it gets more challenging with every round.

Who it's for.

This game is for anyone who wants to test their memory. It's easy enough for children to pick up, but the later rounds give adults a real challenge too.

Why it exists.

Memory Path Game was created as a Code Institute milestone project. The aim was to build a fun responsive game while practising HTML, CSS and JavaScript.

Credits.

  • Game concept: Inspired by the path-memory puzzles in the Brain Age and Big Brain Academy games. Only the concept was borrowed and no code or assets were used.
  • Fonts: Fredoka and Plus Jakarta Sans from Google Fonts.
  • Testing: Jest was used as the testing framework.
